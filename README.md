# CNN-FPGA-Accelerator

The goal of this project is to accelerate inference of a pretrained CIFAR-10 CNN using the programmable logic of the PYNQ-Z2 FPGA.
We have achieved a ×16.70 speedup compared to inference running on a commercial CPU (AMD Ryzen CPU) and a ×129.3 compared to the onboard ARM CPU.
The design of the architecture and reported speedup is layed out in the report.
